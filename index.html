Raspberry Pi YouTube Uploader

This is a private application used to upload videos to YouTube from a Raspberry Pi using the open-source youtubeuploader project.

About

This application uses the YouTube Data API to upload videos to a YouTube channel. The software runs locally on a Raspberry Pi and is intended for private use only.

The application is based on the open-source project: youtubeuploader .

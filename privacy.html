Privacy Policy

Last updated: August 2025

This application uses the YouTube Data API to upload videos to YouTube.

Information Collected

The application accesses Google account information only as required for YouTube authentication and video uploads.

OAuth access tokens and refresh tokens are stored locally on the device where the application runs.

Use of Information

The information obtained through Google OAuth is used exclusively for:

  • Authenticating with YouTube.
  • Uploading videos.
  • Managing upload operations.

Data Sharing

No personal information is sold, shared, rented, or transferred to third parties.

Data Retention and Deletion

OAuth credentials remain stored locally until removed by the user.

Users may revoke access at any time through:

https://myaccount.google.com/permissions

Google Services

This application uses Google APIs and complies with the Google API Services User Data Policy.

Google Privacy Policy: https://policies.google.com/privacy

Google API Services User Data Policy: https://developers.google.com/terms/api-services-user-data-policy
